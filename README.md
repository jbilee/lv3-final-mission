# 레벨3 최종 미션

## 서비스 구성

방과 일자를 선택해 회의실을 예약할 수 있는 서비스입니다. 사용자는 회원가입 후, 원하는 회의실의 ID에 대하여 공실인 날짜 및 시간에 예약을 진행할 수 있습니다.

본 서비스는 서버 API의 형태로 제공되며, 별도의 사용자 인터페이스 화면은 없습니다.

## 적용 인프라

서버 API를 배포하기 위해 AWS에서 제공하는 클라우드 서버를 활용하였습니다.

개발 및 DB 서버는 보안을 위해 외부에 공개되지 않도록 private 네트워크에서 동작하고, 운영 서버는 80 포트로 외부 IP와 통신이 가능하도록 public 네트워크에서 동작합니다.

### 개발 서버

개발 및 운영 서버를 별도로 구축해 개발 환경에서도 개발 담당자 외 다른 인원도 함께 공개적인 IP 주소를 통해 HTTP 통신이 가능하게 하였습니다.

### 운영 서버

운영 환경에서는 스프링 애플리케이션을 실행하는 EC2 인스턴스를 public subnet에 구축하고, 외부와의 통신이 다이렉트로 가능하도록 설정했습니다.

### DB 서버

MySQL 데이터베이스를 구동하는 EC2 인스턴스를 private subnet에 구축해 VPC 내부의 허용된 채널을 통해서만 DB 데이터에 직접적으로 접근할 수 있도록 했습니다.
